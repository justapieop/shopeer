# @shopeer/web-lib

Shared frontend library with API types generated by `openapi-typescript` and a
typed `openapi-fetch` client.

Generate types while the backend is running at `http://localhost:3000`:

```sh
pnpm --filter @shopeer/web-lib generate:api
```

From the repository root, `pnpm generate:api` runs the same script and forwards
any schema URL or file argument. Relative file paths still resolve from
`packages/web-lib`.

Pass another schema URL or a JSON/YAML file as the first argument. File paths
are relative to `packages/web-lib`, where pnpm runs the script:

```sh
pnpm --filter @shopeer/web-lib generate:api https://api.example.com/openapi.json
pnpm --filter @shopeer/web-lib generate:api ./openapi.json
```

`OPENAPI_SCHEMA` also sets the source; a command-line argument takes precedence.
The generated `src/api/schema.d.ts` is committed so builds need no running API.
Regenerate and commit it whenever the backend contract changes.

This package uses TypeScript 5.9 because `openapi-typescript` requires its compiler
API, which is unavailable in TypeScript 7. Other workspace packages keep their
existing compiler versions.

```ts
import { createApiClient } from "@shopeer/web-lib";
import type { components } from "@shopeer/web-lib";

const api = createApiClient({ baseUrl: "http://localhost:3000" });
const { data, error } = await api.GET("/products", {
  params: { query: { page: 1, limit: 20 } },
});

type Product = components["schemas"]["ProductResponseDto"];
```

The client includes browser cookies by default. Cross-origin browser requests
also require the backend to allow the frontend origin and credentials through
CORS. Server-side calls must explicitly forward the incoming cookie through
`headers`; create a client per request when supplying user credentials.

`apps/web` declares a `workspace:*` dependency on this package. It exports
TypeScript source, which Next.js compiles through `transpilePackages`; no separate
library build is needed to start the frontend.

The package inherits the monorepo's strict TypeScript settings with browser and
bundler overrides. Its `build` and `typecheck` scripts validate types without
emitting files; the consuming application produces the JavaScript bundle.

```sh
pnpm --filter @shopeer/web-lib typecheck
```
